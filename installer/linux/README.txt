==================================================
  UNI IDE для Linux — установка
==================================================

1. Распакуйте архив целиком (в любую папку).

2. Откройте в этой папке терминал и выполните:

       ./install.sh

   Программа ставится в вашу домашнюю папку (~/.local/opt/UNI-IDE),
   права администратора для этого НЕ нужны. В меню приложений и на
   рабочем столе появится «UNI IDE».

3. Установщик спросит, настроить ли доступ к плате. Ответьте «Д» и
   введите пароль администратора — это нужно один раз, чтобы программа
   могла прошивать плату ESP32 через USB. Если пароля нет, попросите
   учителя/администратора выполнить:

       ./install.sh --serial

4. Подключите плату к USB и запустите UNI IDE.

Интернет для работы не нужен: компилятор ESP32 уже внутри.
Обновления программа скачивает сама, когда интернет есть.

--------------------------------------------------
ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ
--------------------------------------------------
* Плата не появляется в списке портов (Ubuntu/Debian):
  её перехватывает служба brltty. Удалите её:
       sudo apt remove brltty
  и переподключите плату.

* «Permission denied» при загрузке программы на плату:
  не настроен доступ к порту — выполните  ./install.sh --serial

* Окно программы не открывается, вместо него открылся браузер:
  так задумано как запасной вариант — работать можно и в браузере.
  Чтобы открывалось собственное окно, на Ubuntu/Debian поставьте:
       sudo apt install libxcb-cursor0

* Требуется 64-битный Linux с glibc 2.28 или новее
  (Ubuntu 20.04+, Debian 10+, Astra Linux 1.7+, Альт 10+, РЕД ОС 7.3+).

Удаление:  ~/.local/opt/UNI-IDE/uninstall.sh
(проекты в ~/Uni_Sketches не удаляются)
